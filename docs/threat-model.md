# 威胁模型

## 资产

| 资产 | 位置 | 保护 |
|---|---|---|
| 卡密明文 | 仅生成/导出环节瞬时存在 | 数据库存 HMAC 检索值；导出高危权限+审计 |
| 签名私钥（Ed25519） | KMS/Vault | 客户端只有公钥池 |
| 信封加密私钥（X25519） | KMS/Secret | 分版本轮换 |
| 卡密 HMAC 主密钥 | KMS/Secret | 派生指纹盐密钥（域分离） |
| 授权租约 | 服务端签发、客户端缓存 | Ed25519 签名，短 TTL（分钟级） |
| 管理员凭据 | 数据库（Argon2id） | MFA（TOTP）、锁定策略、会话吊销 |
| 审计日志 | PostgreSQL（追加写） | 高危操作全量留痕 |

## 对手与对策（STRIDE 摘要）

### S（仿冒）
- **伪造服务端**：客户端内嵌公钥池（TOFU 固定 + 可选宿主注入 pin），租约验签失败即拒绝；TLS 1.3 强制。
- **伪造客户端**：激活载荷信封加密 + 设备 PoP 签名（ECDSA P-256，优先 TPM 硬件保护）。
- **复用盗取的租约**：租约绑定设备 ID，业务门禁 `has_feature` 每次校验租约签名、有效期与设备绑定一致性。

### T（篡改）
- **篡改租约字段**（如 `exp`、`feat`）：Ed25519 验签失败即拒绝（E2E 已验证）。
- **篡改请求体**：设备签名覆盖 `sha256(body)`（E2E 已验证）。
- **跨接口重放密文**：信封 AAD 绑定 purpose（activate/redeem）（E2E 已验证）。

### R（抵赖）
- 管理面全部变更操作写审计日志（操作者/前后状态/IP/请求 ID）。
- 制卡、导出、吊销、解绑等高危操作要求原因填写。

### I（信息泄露）
- 抓包无明文卡密（应用层信封加密）。
- 数据库无明文卡密、无原始硬件序列号（分量 SHA-256 摘要 + 服务端盐）。
- 日志无敏感信息（结构化访问日志仅记录路径/状态/耗时/IP）。
- 错误响应不泄漏内部细节（E2E 已验证 SQL/pgx 不外泄）。

### D（拒绝服务）
- 公开接口多维限流（IP 滑动窗口，Redis Lua 原子）。
- 卡密枚举检测（阈值触发渐进封禁 + 风险事件）。
- 无状态多副本 + HPA；Redis 故障时降级放行并记录（可用性优先，DB 仍是事实来源）。

### E（权限提升）
- RBAC 服务端逐请求校验；agent 角色数据范围服务端强制。
- 会话 cookie HttpOnly + SameSite=Strict；写请求 CSRF 双提交校验（E2E 已验证）。
- 登录失败锁定 + 统一错误文案防用户名枚举；Argon2id 恒定路径。

## 明确不承诺（威胁模型的诚实边界）

- **客户端绝对不可破解**：客户端运行在用户控制的设备上，内存可被 dump、二进制可被 patch。
  本系统的目标是抬高绕过成本与缩短攻击收益周期：短租约 + 快速吊销 + 设备绑定 + 持续风控。
- **离线场景的绝对防篡改**：离线宽限期内客户端持有签名租约，篡改本地时间只能延长"STALE 判定"，
  不能延长租约本身的有效期（租约 exp 由服务端签名）。
- **TPM 不可用设备**：无 TPM 机器回退 DPAPI 保护的软件密钥（trust_level=software），
  防伪强度低于 TPM 路径，可按套餐策略收紧。

## 滥用场景与产品化对策

| 场景 | 对策 |
|---|---|
| 卡密暴力枚举 | 130-bit 熵 + 枚举检测 + IP 限流 |
| 一卡多机共享 | 设备绑定上限 + 并发在线名额原子控制（Lua）+ 异常换机告警 |
| 盗卡后转卖 | 管理员一键吊销（一个心跳周期内传播到在线客户端）+ 级联冻结 |
| 恶意刷激活 | 多维限流 + 渐进延迟 + 封禁（IP/设备/前缀/版本/ASN） |
| 内部人员滥权 | RBAC + 高危操作二次确认 + 全量审计 |
